base32-key

Encode numbers as readable keys like 222ET-3ZZGN. No look-alike characters, and every group of five carries its own check digit, so a typo points at the exact group. GitHub · API reference · npm

Signed keys

signKey adds an HMAC-SHA256 tag, so only someone with the secret can make a valid key. The secret stays on your server in real use; here everything runs in your browser.

Generate

    On the server: Python and Go

    The same keys in other languages, tested against the shared test vectors: a key made on this page decodes there, and the other way round.

    Python 3.9+ (PyPI) 

    pip install base32-key

from base32_key import from_hex, to_hex, validate, suggest, sign_key, verify_key

from_hex("c0ffee")                      # '222ET-3ZZGN'
to_hex("222et 3zzgn", normalize=True)   # 'c0ffee'
validate("222ET-3ZZGX")                 # (False, [1], 'CHECKSUM_MISMATCH')
suggest("222TE-3ZZGN")                  # ['222ET-3ZZGN']
key = sign_key(b"\x00\x00\x01\x2a", "s3cret")
verify_key(key, "s3cret")               # b'\x00\x00\x01*'

    Go 1.22+ (pkg.go.dev) 

    go get github.com/ducminhquan/base32-key/go@latest

import base32key "github.com/ducminhquan/base32-key/go"

key, _ := base32key.FromHex("c0ffee", base32key.DefaultOptions) // "222ET-3ZZGN"
res := base32key.Validate("222ET-3ZZGX", base32key.DefaultOptions)
// res.Valid == false, res.InvalidGroups == [1]
base32key.Suggest("222TE-3ZZGN", base32key.DefaultOptions, 0) // ["222ET-3ZZGN"]
